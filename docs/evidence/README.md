# Evidence Logs

This directory contains evidence logs generated by the personal finance assistant agent and its automated evaluation and interactive runs.

## Log Files and Covered Phases

### `run_20261016.jsonl`
This log file captures all structured JSON Lines (JSONL) events recorded by `src/logger.py` with ISO 8601 timestamps, sanitized payloads (secrets redacted), and `history_turns` tracking.

It covers the following development phases:
- **Phase 8 (Logging and Evidence):** Emits structured audit events (`question`, `tool_call`, `tool_result`, `permission_denied`, `budget_proposed`, `budget_applied`, `budget_cancelled`, `final_answer`).
- **Phase 9 (Evaluation Suite):** Automated execution and tool assertions across the 18 evaluation questions in `eval/questions.json`.
- **Phase 10 (Simulated Sandbox Date):** As-of date normalization (`2026-08-31`) across tool queries and prompt definitions.
- **Phase 11 (Approval Workflow Separation):** Out-of-band budget approval requests and confirmations (`/apply`, `/pending`) via `src/approvals.py` without model invocation of sensitive operations.
- **Phase 12 (Conversation Memory):** Multi-turn context preservation (up to 10 conversation turns) with explicit `history_turns` tracking on every question event.
- **Phase 13A & Phase 13A Fix (Financial Analysis Tools & Assertions):**
  - Read-only analysis tools: `cashflow_projection`, `detect_spending_spikes`, and `savings_recommendations`.
  - Side-by-side pandas alignment for starting balance ($7,564.57), 30-day scheduled bills ($1,869.99), daily discretionary spending ($36.14), and monthly spending spikes (July Dining +$344.00, August Health +$377.80).
  - Strengthened evaluations for q16 (Dining spike), q17 (Cashflow bill coverage and simulated sandbox balance label), and q18 (Health savings to prior month).
