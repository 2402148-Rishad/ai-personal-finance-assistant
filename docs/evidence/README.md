This folder contains evidence logs generated by the personal finance assistant agent and its permission-enforced tool execution workflows.

## Log Files

- **Description:** Structured JSON Lines (JSONL) recording agent events, permission decisions, tool executions, and budget state transitions with ISO 8601 timestamps and sanitized payloads (API keys and `.env` secrets redacted).
- **Contents Demonstrated:**
